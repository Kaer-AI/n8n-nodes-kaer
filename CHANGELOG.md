# Changelog

## 0.1.1

First release.

- Kaer node with one operation, Search, on the `web`, `fast`, `deep` and `auto` lanes.
- Options for domain filters, offset and page, response fields, and one item per result or the full response.
- Kaer API credential, tested with the free `GET /v1/me` call.
- Usable as a tool by n8n AI Agent nodes.
